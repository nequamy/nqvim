
# Конфигурация NEOVIM v0.12 (nigtly)


# Описание конфигурации

Данная конфигурация в основном направлена на написания кода на RUST с дополнительной поддержкой языка программирования Python 
В сборке существует в общей сложности 21 плагин:
- mason работа с LSP-серверами
- lualine
- fzf-lua 
- nvim-cmp
- treesitter
- comments
- nvim surround
- nvim-autopairs
- which-key
- nvim-dev-icons
- neo-tree
- rustaceanvim
- dashboard-nvim
- trouble
- gitsigns
- crates
- compiler-explorer
- venv-selecotor
- todo-comments

# Требования

- Neovim v0.12+
- Git

# Установка

```
git clone git@github.com:nequamy/nqvim.git ~/.config/nvim/
```
